# HU-2
tienda virtual js para simular el flujo de comercio electronico
Proyecto de Estructuras de Datos en JavaScriptEste proyecto demuestra el uso práctico de objetos, Set y Map en JavaScript para almacenar, filtrar e iterar datos de forma eficiente.
CaracterísticasGestión de Objetos: Definición y filtrado de productos comerciales.Manipulación de Sets: Eliminación automática de duplicados y operaciones clave (add, has, delete).Uso de Maps: Asociación estructurada de categorías y nombres de productos.Estrategias de Iteración: Demostración de bucles for...in, for...of y forEach.
estructura del codigo
1. Objetos y ValidaciónSe define un objeto base con productos informáticos.Se aplica un filtro estricto mediante Object.entries() y forEach() para asegurar la integridad de los datos.
2. Colecciones SetSe inicializa un Set con números duplicados para observar la limpieza automática de datos.Se ejecutan métodos de búsqueda, inserción y borrado.
3. Colecciones Map Se crea un diccionario clave-valor para mapear categorías con productos previamente validados.
Instrucciones de UsoCopie el código fuente en un archivo llamado gestion_de_datos.js y index.html ejecute el index con click derecho y dar click en la opcion open with live server, abrir la terminal del navegador con f12
